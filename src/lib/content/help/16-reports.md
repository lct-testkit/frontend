# Отчёты

Отчёты отвечают на вопросы «как идёт воронка», «кто и сколько закрыл», «какие программы востребованы» и выгружают данные в Excel, PDF и другие форматы. Они строятся только по тем данным, к которым у вас есть доступ.

## Где найти

Пункт «Отчёты» в боковом меню (виден менеджеру, руководителю и администратору). Три вкладки: «Отчёты» (шаблоны), «Мои отчёты» (история ваших запусков) и «Дашборды» (виджеты, которые обновляются вручную).

## Шаблоны

В поставке 13 шаблонов. Шаблон открывается в панели справа: параметры, формат и кнопка «Запустить».

| Шаблон | Что показывает | Кто видит | Форматы |
| --- | --- | --- | --- |
| Воронка по статусам | Конверсия и среднее время между шагами воронки | менеджер, руководитель, администратор | Excel (xlsx, xls), PDF, PNG, JSON |
| Сводка по КАМам | Сравнение менеджеров: сделки в работе, выиграно, проиграно, сумма, средний цикл | руководитель, администратор | xlsx, xls, PDF, JSON |
| По регионам | Сделки и выигранная сумма по регионам вузов | все трое | xlsx, xls, PDF, JSON |
| Причины отказов | Распределение проигранных сделок по причинам из справочника | все трое | xlsx, xls, PDF, JSON |
| Соблюдение SLA | Доля сделок в норме, под угрозой и с нарушением срока | все трое | xlsx, xls, PDF, JSON |
| Динамика по месяцам | Создано, выиграно, проиграно и выигранная сумма по месяцам | все трое | xlsx, xls, PDF, PNG, JSON |
| Зависшие сделки | Список сделок с нарушенным сроком | все трое | xlsx, xls, PDF, JSON |
| Сделки по вузам и направлениям | Реестр сделок за период по вузу, направлению, продукту, статусу и ответственному | все трое | xlsx, xls, PDF, JSON |
| Прогресс обучения | Прогресс учащихся по данным LMS: процент прохождения, оценка, даты, поток | все трое | xlsx, xls, PDF, PNG, JSON |
| Загрузка пользователей в LMS | Учащиеся оплаченных сделок физлиц в формате шаблона LMS. **Содержит персональные данные**, формат только xlsx | руководитель, администратор | xlsx |
| Рейтинг востребованности ИТ-продуктов и направлений | Ранжирование по заявкам, числу обучающихся и параллельных потоков | все трое | xlsx, xls, PDF, PNG, JSON |

«Прогресс обучения» пуст, пока система LMS не присылала данных.

## Шаги: запустить отчёт

1. Откройте вкладку «Отчёты» и выберите шаблон.
2. Заполните параметры. У табличных отчётов один набор фильтров: период (с выбором даты, по которой он считается), вузы, направления, продукты и ответственные по сделке. Пустое поле — без ограничения. У отчётов «Динамика по месяцам» и «Подписание по периодам» срок задают двумя способами: «Последних месяцев» (от 1 до 36) или свой период; если выбран свой период, берётся он, а число месяцев становится неактивным. Списки ищут на сервере: начните вводить название, а если вариантов много, нажмите «Показать ещё». У отчётов с настраиваемыми колонками есть блок «Колонки»: отметьте нужные, задайте порядок или нажмите «Как в ТЗ».
3. Выберите формат (выбор запоминается для каждого отчёта) и нажмите «Запустить».
4. Лёгкий отчёт готов сразу, тяжёлый ждёт в очереди (обычно до минуты). Панель можно закрыть кнопкой «Свернуть»: о готовности сообщит уведомление, а результат появится во вкладке «Мои отчёты».

## Статусы в «Моих отчётах»

| Статус | Значение |
| --- | --- |
| В очереди | Отчёт ждёт своей очереди |
| Формируется | Идёт расчёт |
| Готов | Файл можно скачать (кнопка «Скачать», для данных — «Скачать JSON») |
| Ошибка | Не получилось; текст причины показывается рядом |
| Срок хранения истёк | Файл удалён; кнопка «Запустить заново» повторит отчёт с теми же параметрами |

Ссылка на скачивание действует 15 минут, сам файл хранится 7 дней. Пометки в таблице: «Усечено» — строк больше предела (показано число), «Снимок» — данные взяты из снимка, который обновляется раз в 5 минут (с фильтрами отчёт считается по актуальным данным); время данных показано рядом.

## Лимит

Одновременно в работе может быть до 10 ваших отчётов. Если лимит исчерпан, панель покажет, сколько отчётов в работе, и сама включит «Повторить», когда место освободится (код `CRM-1601`; по теме есть также `CRM-1602`: отчёт ещё не готов, и `CRM-1603`: срок хранения истёк — см. [«Коды ошибок»](?s=errors#h-crm-1601)).

## Дашборды

Виджеты обновляются вручную кнопкой «Обновить данные», чтобы не создавать лишних выгрузок. У каждого виджета есть меню «Скачать»: график и показатель — PNG, PDF и JSON, таблица — JSON и «Таблица (Excel, PDF)…».

## Каждая выгрузка записывается в журнал

Выгрузка отчёта записывается в журнал аудита. Отчёт «Загрузка пользователей в LMS» содержит персональные данные: храните и передавайте его как документ с ПДн.
