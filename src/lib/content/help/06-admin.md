# Администрирование

**Пользователи.** Учётная запись создаётся администратором; сотрудник получает приглашение. Блокировка немедленно завершает все сессии, сделки остаются за сотрудником и помечаются для руководителя. При увольнении работает мастер передачи дел: система показывает, что держит сотрудник, и переназначает сделки одним подтверждением.

**«Четыре глаза».** Создание администратора и необратимые операции требуют подтверждения вторым администратором — раздел «Согласования».

**Удаление персональных данных.** Запрос проверяет блокеры (активные сделки, подписи, законные основания хранения), даёт срок отсрочки и формирует акт об уничтожении. Подписанные документы не обезличиваются.

**Журнал аудита.** Неизменяемый: каждая запись связана хэшем с предыдущей, целостность проверяется кнопкой. Есть фильтры, экспорт и запись об отказах в доступе.

**Настройки.** Флаги функций и системные параметры; секреты показываются маской.
