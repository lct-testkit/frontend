# Воронка из 14 шагов

Основная воронка работы с вузом повторяет путь из задания: от поиска контактов ответственного до контроля за исполнением. Здесь описано, что значит каждый шаг в системе, что нужно сделать, чтобы перейти дальше, и что произойдёт автоматически.

## Где это видно

В карточке сделки типа «Организация» над вкладками — лента шагов («Шаг 3 из 14»): пройденные залиты, текущий выделен, необязательный пропущенный шаг показан пунктиром. Кнопки переходов под названием сделки предлагают только допустимые шаги для вашей роли. Исполнение по каждому этапу (сколько времени заняло, уложились ли в срок, сколько комментариев и файлов) — на вкладке «Этапы».

Воронка называется «B2B: взаимодействие с вузом (14 шагов задания)» и выбрана по умолчанию для сделок с организациями. Администратор может изменить её в конструкторе воронок; ниже описано состояние из поставки. Дополнительная воронка «B2B: продажа КП с юридическим согласованием» по умолчанию не используется, сделки с физлицами идут по воронке «B2C: обучение физлица» из шести шагов.

## Шаги

Срок указан в рабочих днях. На 75% срока включается предупреждение, после срока сделка отмечается просроченной, а при сильной просрочке руководителю уходит уведомление (эскалация). Условия перехода «вперёд» показывает чек-лист в диалоге перехода. Названия статусов в системе повторяют шаги задания с заглавной буквы (у шага 5 в конце добавлено «(опционально)»).

**Кто двигает сделку.** Менеджер, руководитель и администратор проводят сделку по шагам 1–13. Закрытие на шаге 14 доступно только руководителю (администратор может всё).

**Новый цикл.** С шага 14 есть переход «Начать новый цикл занятий (пролонгация)» на шаг 11 (комментарий обязателен): занятия, документация и повышение квалификации повторяются каждый семестр.

## Что есть на каждом шаге

- **Вернуться на предыдущий шаг** — нужен комментарий с причиной.
- **Отказ** — нужен комментарий и «Причина отказа» из справочника. Сделка закрывается как проигранная.
- **Заморозить** — нужен комментарий и дата возобновления либо причина заморозки. Пока сделка заморожена, таймер срока стоит.
- **Возобновить** — из заморозки сделку возвращают на любой шаг (нужен комментарий).
- **Закрыть успешно** — только на шаге 14, статус «Успешно закрыта» требует сумму и плановую дату закрытия.

## Если не получилось

- Кнопки перехода нет — у вашей роли нет права на этот переход (так устроен шаг 14) или сделка уже закрыта.
- Диалог говорит, что условия не выполнены — в чек-листе перечислено, чего не хватает: файл на этом шаге, комментарий, подпись. Подробнее — главы [«Файлы в сделке»](?s=files) и [«Электронная подпись»](?s=signing); код ошибки — [`CRM-1201`](?s=errors#h-crm-1201) и соседние.
