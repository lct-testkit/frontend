# Быстрый старт

**Вход.** В демо-режиме выберите роль на экране входа. В рабочем режиме вход идёт через корпоративную учётную запись (Keycloak); при первом входе нужно принять политику обработки персональных данных.

![Экран входа в демо-режиме: карточки ролей](/help/login.png)

## Кто что может

В системе четыре роли для людей. Менеджер (КАМ) ведёт свои сделки. Руководитель видит сделки своей команды, передаёт сделки и запускает импорт. Администратор настраивает воронки, справочники, пользователей и интеграции. Аудитор читает журнал аудита и соглашения об ЭДО, но не видит сделок и контактов. Права проверяет сервер: кнопка, которой нет в меню, недоступна и напрямую.

| Действие | КАМ | Руководитель | Администратор | Аудитор |
| --- | --- | --- | --- | --- |
| Видит сделки | свои и те, где участник | команды | все | нет |
| Создаёт и ведёт сделки | да | да | да | нет |
| Переназначает сделки | нет | да | да | нет |
| Импорт каталогов и откат импорта | нет | да | да | нет |
| Отчёты | да | да | да | нет |
| Отчёты «Сводка по КАМам» и «Загрузка пользователей в LMS» | нет | да | да | нет |
| Подписание: создаёт и подписывает | да | да | да | только читает |
| Аннулирует подписание | нет | да | да | нет |
| Удаляет файлы | нет | да | да | нет |
| Журнал аудита | нет | только команда | весь | весь |
| Выгрузка журнала | нет | нет | да | да |
| Воронки, справочники, интеграции, пользователи, настройки | нет | нет | да | нет |

Что делает каждая роль по шагам — в главах «Менеджер (КАМ)», «Руководитель», «Администратор» и «Аудитор».

**Навигация.** Меню слева показывает только доступные вам разделы. Значок «свернуть» внизу меню оставляет иконки. На телефоне меню открывается кнопкой в шапке.

**Поиск.** Строка в шапке ищет по сделкам, организациям и контактам. Быстрый доступ — `Ctrl` + `K` (на Mac — `⌘` + `K`); стрелки и `Enter` выбирают результат.

**Тема.** Переключатель светлой и тёмной темы — в шапке; палитра меняется в профиле.

**Что на главной.** Сделки в работе и их сумма, просроченные по SLA, ваши задачи, документы на подпись и воронка по статусам.
