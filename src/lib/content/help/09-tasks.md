# Задачи, уведомления, профиль

**Мои задачи.** Раздел «Задачи» собирает задачи по всем сделкам: вкладки «Открытые», «В работе», «Просроченные», «Выполненные» и «Все», группы по сроку, фильтр по приоритету. Флажок отмечает задачу выполненной. Руководитель и администратор видят задачи всей своей команды и могут выбрать сотрудника.

**Колокольчик.** Точка на колокольчике в шапке — есть непрочитанные. Панель показывает последние десять; «Прочитать все» отмечает все, «Все уведомления» открывает полный список. Уведомление о задаче ведёт прямо к ней, уведомление о сделке — в её карточку.

**Что и как присылать.** В настройках уведомлений для каждого события включается своё, выбираются каналы (в приложении, почта, Telegram) и задаются тихие часы. В приложении уведомления приходят всегда; почта уходит наружу, если администратор стенда настроил почтовый сервер (`SMTP_HOST`), иначе остаётся в очереди; Telegram в этой сборке не подключён.

**Профиль.** Данные учётной записи, список ваших сессий и смена пароля с проверкой правил по мере ввода. Палитра темы выбирается там же.
