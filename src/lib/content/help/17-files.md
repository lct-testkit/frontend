# Файлы в сделке

К сделке прикладывают договоры, презентации, акты и другие документы. Файлы нужны не только для архива: у многих переходов воронки есть условие «приложен файл нужной категории», и пока его нет, сделка дальше не пойдёт.

## Где найти

Вкладка «Файлы» в карточке сделки. Такая же вкладка есть в карточке организации. Файл можно приложить и прямо в диалоге перехода, не выходя из него (ниже). Что и на каком этапе приложено, видно на вкладках «Этапы» (колонка «Файлы») и «История» (под записью о переходе).

## Категории

Каждый файл относится к одной из семи категорий. Её выбирают перед загрузкой в поле «Категория»; список сгруппирован по категориям с числом файлов.

| Категория | Для чего |
| --- | --- |
| Договор | Договоры и черновики договоров |
| Презентация | Презентации для вуза |
| Акт | Акты передачи, приёмки |
| Лицензия | Документы по лицензиям |
| Отчёт | Отчёты и справки |
| Контейнер подписи | Файлы, созданные при электронном подписании |
| Прочее | Всё остальное (по умолчанию) |

## Шаги: загрузить, скачать, убрать

1. Выберите категорию в поле «Категория».
2. Перетащите файлы в зону «Загрузить файлы» или выберите их кнопкой. Файлы грузятся напрямую в хранилище, крупные показывают прогресс; несколько файлов идут по очереди.
3. Скачать файл можно кнопкой «Скачать» в строке (есть у тех, кто вправе скачивать файлы).
4. Кнопка «Отвязать» убирает файл из сделки. Её видят руководитель и администратор: менеджер удалять файлы не может.

## Какие файлы принимаются

- Расширения: png, jpeg, jpg, pdf, zip, gz, gzip, rar, doc, docx, xls, xlsx, xml, csv, json. SVG запрещён всегда.
- Размер: интерфейс принимает файл до 50 МБ. Сервер для вложений сделки допускает больше (по умолчанию до 500 МБ), но через экран такой файл не загрузить.
- Список расширений и лимиты задаёт администратор при установке; если сервер отклонил файл, причина показана в строке очереди (коды `CRM-1401` и `CRM-1402`, см. [«Коды ошибок»](?s=errors#h-crm-1401)).

## Статус файла

Система хранит у файла один из пяти статусов. В списке вложений они не показываются, но влияют на скачивание.

| Статус | Что значит |
| --- | --- |
| Загружается | Файл передаётся или ещё не прошёл проверку: скачать нельзя, подождите несколько секунд |
| Готов | Файл проверен, его можно скачать |
| Не прошёл проверку | Содержимое не совпало с расширением (например, файл .pdf другого формата): скачивание заблокировано |
| В карантине | Статус предусмотрен, но система его сейчас не присваивает |
| Удалён | Файл убран из хранилища |

**Честно о проверке.** Антивирусный сканер в поставку не подключён, поэтому файл проверяется по расширению, сигнатуре и контрольной сумме. Вредоносное содержимое в корректном по формату файле такая проверка не обнаружит. Ссылки на скачивание выдаются после проверки прав и живут недолго.

## Как файл влияет на переход

У перехода воронки может быть условие вида «приложен файл категории X». Условия бывают двух видов:

- «Прикреплён договор» (и другие категории): подходит файл этой категории, приложенный к сделке на любой вкладке;
- «Приложен договор»: файл должен быть приложен **на этом шаге** воронки (так устроены шаги 4–7 и 14 воронки из 14 шагов, см. [«Воронка из 14 шагов»](?s=funnel)).

Диалог перехода показывает чек-лист: выполненное условие — тихая строка с галочкой, невыполненное — плашка с кнопкой перехода («К файлам»). Файл можно приложить прямо в диалоге: категория там уже выбрана, файл привязывается к сделке и записывается в историю этого перехода. Если условие не выполнено, сервер ответит кодом `CRM-1205` (или `CRM-1201`), а диалог перечислит, чего не хватает.

## Если не получилось

- «Такой тип файла не разрешён» или «Файл слишком большой» — см. раздел «Какие файлы принимаются».
- «Файл не прошёл проверку безопасности» — пересохраните файл в нужном формате и загрузите снова (`CRM-1403`).
- Кнопки «Отвязать» нет — у менеджера нет права удалять файлы; обратитесь к руководителю.
