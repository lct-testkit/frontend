# Безопасность и персональные данные

![Смена пароля: правила проверяются по мере ввода](/help/security.png)

* **Пароль** — не короче 12 символов, отличается от текущего, не содержит имя учётной записи, не повторяет ни один из последних пяти; правила проверяются по мере ввода. Смена пароля завершает все остальные сессии.
* Администратор может потребовать у сотрудника **второй фактор (TOTP)** — код из приложения-аутентификатора при каждом входе; включается при создании пользователя.
* Сессия привязана к серверу; токены недоступны скрипту страницы.
* Все изменения данных попадают в неизменяемый журнал, включая отказы в доступе и раскрытие персональных данных.
* Права проверяются на сервере: скрытая в интерфейсе кнопка — не единственная защита.
* Файлы проверяются на вирусы и по типу; ссылки на скачивание выдаются после проверки прав и живут недолго.
* Персональные данные контактов маскируются; раскрытие фиксируется.
