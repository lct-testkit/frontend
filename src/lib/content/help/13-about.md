# О проекте

**Команда «Тесткит».** RTK School CRM — внутренняя CRM ИТ Школы Ростелекома для продаж образовательных программ вузам и физическим лицам. Её сделала команда «Тесткит»: [страница команды на GitHub](https://github.com/lct-testkit) — путеводитель по репозиториям со ссылками на всё ниже.

**Из чего собрано.** Веб-клиент на SvelteKit и Svelte 5; API на FastAPI с PostgreSQL, Redis и фоновым воркером; Keycloak для входа; файловое хранилище SeaweedFS (S3). Интерфейс — на своей дизайн-системе rt-ui (см. главу «Дизайн-система»). Всё упаковано в Docker; для сервера есть готовые образы, Helm-чарт, автодеплой и офлайн-бандл со всеми образами для закрытого контура.

**Где посмотреть.**

* [README продукта](https://github.com/lct-testkit/.github#readme) — запуск, роли, соответствие требованиям кейса, библиотеки, ранбук;
* [бэкенд](https://github.com/lct-testkit/backend#readme) — API, модель данных, права, аудит; Swagger UI — на `/api/docs` у стенда;
* [веб-клиент](https://github.com/lct-testkit/frontend#readme) — блоки интерфейса, редактор воронки, интеграция с Битрикс24;
* [rt-ui](https://github.com/lct-testkit/rt-ui#readme) — дизайн-система: компоненты, темы, сверка с оригиналом;
* [deploy](https://github.com/lct-testkit/deploy#readme) — конвейер поставки, RUNBOOK, релизы.

**Как проверяли.** Каждое изменение проходит линтеры, типы, тесты на настоящей базе, проверку контракта API и сканеры уязвимостей; интерфейс отдельно обходят автоматически — все экраны под всеми ролями и размерами, каждую кнопку, размер нажимаемых целей. Интеграция с Битрикс24 проверена на живом портале.

**Честно о границах.** Входящий поток Битрикс24 работает по упрощённому контракту; Telegram не подключён, почта работает только при настроенном почтовом сервере; для части новых методов API интерфейс ещё не построен. Полный список — в разделе «Ограничения» README.

**Материалы третьих лиц.** Шрифт Rostelecom Basis и фирменные материалы дизайн-системы принадлежат Ростелекому и в репозитории не хранятся. Исходный код доступен организаторам, жюри и экспертам для ознакомления, запуска и проверки.
