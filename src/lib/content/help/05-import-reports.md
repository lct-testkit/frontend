# Импорт и отчёты

**Импорт каталогов** (.xlsx, .xls, .csv) идёт по шагам: загрузка → проверка структуры → сопоставление колонок → пробный прогон с отчётом об ошибках → применение. Сопоставление можно сохранить пресетом. Строки с ошибками пропускаются, весь импорт не падает; применённый импорт можно откатить.

**Отчёты.** Выберите шаблон, задайте период и формат (xlsx, pdf, png). Тяжёлые отчёты строятся в фоне — прогресс виден в истории, готовый файл скачивается по одноразовой ссылке. Отчёт содержит только те данные, к которым у вас есть доступ, а каждая выгрузка записывается в журнал аудита.

**Дашборды.** Виджеты обновляются вручную, чтобы не создавать лишних выгрузок.
