# Импорт и отчёты

**Импорт каталогов** (.xlsx, .xls, .csv, до 50 МБ) идёт по шагам: загрузка → сопоставление колонок → пробный прогон с отчётом об ошибках → применение. Сопоставление можно сохранить пресетом, автоподбор колонок предлагает совпадения сам. Строки с ошибками пропускаются, весь импорт не падает; применённый импорт можно откатить.

![Первый шаг мастера: что загружаем, что делать с уже существующими записями, файл](/help/import-wizard.png)

**Отчёты.** Выберите шаблон и формат (xlsx, pdf, png). Тяжёлые отчёты строятся в фоне — прогресс виден в истории, готовый файл скачивается по одноразовой ссылке (действует 15 минут, сам файл хранится 7 дней). Отчёт содержит только те данные, к которым у вас есть доступ, а каждая выгрузка записывается в журнал аудита.

**Дашборды.** Виджеты обновляются вручную, чтобы не создавать лишних выгрузок.
