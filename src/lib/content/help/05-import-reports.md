# Импорт и отчёты

**Импорт каталогов** (.xlsx, .xls, .csv, до 50 МБ) идёт по шагам: загрузка → сопоставление колонок → пробный прогон с отчётом об ошибках → применение. Сопоставление можно сохранить пресетом, автоподбор колонок предлагает совпадения сам. Строки с ошибками пропускаются, весь импорт не падает; применённый импорт можно откатить.

![Первый шаг мастера: что загружаем, что делать с уже существующими записями, файл](/help/import-wizard.png)

**Отчёты.** Выберите шаблон, формат и параметры, нажмите «Запустить». Отчёт содержит только те данные, к которым у вас есть доступ, а каждая выгрузка записывается в журнал аудита.

**Фильтры и колонки.** У табличных отчётов один набор фильтров: период (с выбором даты, по которой он считается), вузы, направления, продукты и ответственные по сделке. Пустое поле — без ограничения. Списки ищут на сервере: начните вводить название, а если вариантов много, нажмите «Показать ещё». У отчётов с настраиваемыми колонками есть блок «Колонки»: отметьте нужные, задайте порядок или нажмите «Как в ТЗ».

**Форматы и сроки.** Доступные форматы показаны в панели запуска: Excel .xlsx и .xls, PDF, PNG, JSON. Выбор запоминается для каждого отчёта. Ссылка на скачивание действует 15 минут, сам файл хранится 7 дней; после этого в «Моих отчётах» появится «Срок хранения истёк» и кнопка «Запустить заново» с прежними параметрами.

**Очередь и лимит.** Одновременно в работе может быть до 10 ваших отчётов. Лёгкий отчёт готов сразу, тяжёлый ждёт в очереди — обычно до минуты. Панель можно закрыть кнопкой «Свернуть»: о готовности сообщит уведомление. Если лимит исчерпан, панель покажет, сколько отчётов в работе, и сама включит «Повторить», когда место освободится.

**Усечение и снимок.** Если строк больше заданного предела, у отчёта и виджета появляется пометка «Усечено» с числом строк. Пометка «Снимок» означает, что данные взяты из снимка, который обновляется раз в 5 минут; с фильтрами отчёт считается по актуальным данным. Время данных показано рядом с отчётом.

**Дашборды.** Виджеты обновляются вручную кнопкой «Обновить данные», чтобы не создавать лишних выгрузок. У каждого виджета есть меню «Скачать»: график и показатель — PNG, PDF и JSON, таблица — JSON и «Таблица (Excel, PDF)…».
