# Электронная подпись (ПЭП)

**Как это работает.** Документ формируется из шаблона или загружается файлом; система фиксирует его хэш. Подписант получает ссылку, открывает документ, подтверждает личность кодом из СМС или письма и подписывает. Подпись привязана к хэшу: изменённый документ подписать нельзя.

**Внутренние подписанты** видят задачи в разделе «Подписание». **Внешние** (представители вузов) получают ссылку без регистрации, срок действия — 7 дней.

**Соглашение об ЭДО.** Пока у контрагента нет действующего соглашения, запрос подписи блокируется — сначала оформите соглашение (раздел «Соглашения ЭДО»).

**Проверка.** У каждого подписанного документа есть страница проверки: по QR-коду из штампа или по идентификатору подписи. Там же можно загрузить файл и сверить хэш — файл не покидает браузер.

**Ограничения.** ПЭП не заменяет квалифицированную подпись там, где закон требует её (договоры с обязательной нотариальной формой, отчётность в госорганы).
