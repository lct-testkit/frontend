# Дизайн-система rt-ui

Интерфейс собран на **rt-ui** — нашем порте дизайн-системы Ростелекома на Svelte 5. Это не оболочка над чужим кодом: каждый компонент сверяется с оригиналом, а расхождение печатается списком с картинками.

**Что внутри.** 111 компонентов, 1349 иконок, четыре темы, таблица, которая держит тысячи строк, и графики для дашбордов. Из 374 эталонных историй сходятся все 374: сравниваются DOM, геометрия и пиксели.

**Как подключена.** Пакет `@lct-testkit/rt-ui` ставится из GitHub Packages. Токены темы (цвета, отступы, радиусы, шрифты) вшиты в Tailwind v4, поэтому обычные утилиты — `bg-surface`, `text-muted`, `rounded-md` — сами следуют теме, и отдельных вариантов для тёмной темы нет. Слой rt-ui лежит ниже утилит: утилита всегда побеждает стиль компонента.

**Что своё.** Там, где в rt-ui есть компонент, используется он: кнопки, поля, таблица, окна, вкладки, тосты, графики. Своё — раскладка страниц, карточка-секция, аватар, скелетон, плитка показателя, ввод кода из СМС: их в rt-ui нет.

**Как это проверяется.** Цвета в интерфейсе берутся только из токенов (это проверяет stylelint), а каждый блок принимается в светлой и тёмной темах на ширинах 1440, 1024, 390 и 360 px.
