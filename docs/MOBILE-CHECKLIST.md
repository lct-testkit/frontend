# Чек-лист мобильных видов

Размеры: телефон 390×844, малый 360×640, самый узкий 320×568 (WCAG 1.4.10), горизонтально 844×390, планшет 768×1024, увеличение 200 % (640×450).
Строка «пройдена», когда: нет горизонтальной прокрутки страницы, нет обрезанных колонок и элементов за краем, нет целей касания меньше 44 px (вне абзацев), нет ошибок консоли, главное действие достижимо без масштабирования.

Автопроверки (нужен живой стенд; на мок-стенде F8-4 они запустятся без правок):

| Что | Команда |
|---|---|
| вёрстка, прокрутка, консоль, сеть | `node tools/qa-all.mjs --as kam,admin --sizes phone,phone-s,phone-xs,phone-l,zoom-200` |
| зоны касания | `node tools/taps.mjs --as admin --urls /deals,/organizations,/tasks,/signing` |
| сдвиги вёрстки | `node tools/cls.mjs` |
| доступность DOM | `node tools/a11y.mjs` |

Прогон 2026-10-18 (kam, admin; 38 маршрутов, динамические — по первой записи): телефон 320 — одна находка (`/catalog/custom-fields`, сегментный переключатель шире экрана) — исправлена, остальное чисто; 200 % и 844×390 — чисто; зоны касания — 0 малых целей на 12 экранах.
